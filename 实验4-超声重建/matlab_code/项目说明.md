1. 文件结构
```bash
ultrasound_reconstruction/  # 项目根目录
├── raw_data/
│   └── RF/
│       └── 2025_12_25__14_50_56/  # 存放原始.pgm RF数据
├── wht_liver_dat/  # 生成的.dat二进制文件存放目录（自动创建）
├── ultrasound_results/  # 重建结果保存目录（自动创建，可选）
├── ConvertPgmToDat.m  # 功能1：.pgm -> .dat 格式转换
├── SignalImportAndPreprocess.m  # 功能2：RF信号导入与预处理
├── SpectrumAnalysisAndCenterFreq.m  # 功能3：频谱分析与中心频率确定
├── FilterDesignAndBatchProcess.m  # 功能4：滤波器设计与批量信号滤波
├── SignalDecimationAndBModeImaging.m  # 功能5：信号抽取与B超矩形成像
├── ImageRearrangement.m  # 功能6：B超图像重排
├── SectorImageTransformation.m  # 功能7：凸阵探头扇环图像转换
├── MainUltrasoundReconstruction.m  # 主工作流：串联所有模块完成重建
└── README.md  # 使用说明
```
