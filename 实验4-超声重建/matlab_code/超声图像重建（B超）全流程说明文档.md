# 超声图像重建（B超）全流程说明文档

# 一、项目概述

## 1.1 项目目标

本项目旨在实现一套完整的超声B超图像重建流程，通过模块化设计，将原始超声射频（RF）信号（存储于.pgm格式文件）经过格式转换、信号预处理、频谱分析、滤波、信号抽取、成像及坐标变换等一系列步骤，最终生成符合临床观察习惯的凸阵探头扇环B超图像，同时保留全流程中间数据供后续分析与优化。

## 1.2 核心应用场景

适用于超声医学影像领域的基础研究与临床前实验，可对肝脏等脏器的超声RF原始数据进行离线重建与分析，帮助研究人员直观观察组织超声信号特征、验证信号处理算法效果，为超声设备算法优化、临床诊断辅助提供数据支撑。

## 1.3 技术架构与核心优势

项目采用Matlab模块化开发，将全流程拆分为8个功能独立的函数模块，通过主工作流脚本串联执行。核心优势包括：① 模块化设计，便于单个模块的调试与替换；② 全流程自动化，无需手动干预各环节；③ 保留完整中间数据与可视化结果，便于流程追溯；④ 适配凸阵探头特性，生成符合临床观察的扇环图像；⑤ 严格遵循Matlab语法规范，文件名均以字母开头，确保代码可直接运行。

## 2.2 各模块文件详细说明

### 2.2.1 主工作流模块：MainUltrasoundReconstruction.m

**目的**：作为项目入口，按预设流程顺序调用所有功能模块，实现从原始.pgm文件到扇环B超图像的全流程自动化执行，无需用户手动逐一调用模块。

**核心原理**：通过Matlab的函数调用机制，依次触发格式转换、信号导入、频谱分析、滤波、成像、图像重排、扇环变换等环节，同时传递各环节所需的输入参数与中间数据，确保流程连贯性。

**实现方法**：脚本开头通过clear和clc清理工作区与命令行窗口，避免残留变量干扰；随后按顺序调用7个功能模块，严格遵循“前一模块的输出为后一模块的输入”的逻辑，最终完成全流程重建。

**关键特性**：无输入输出参数，直接运行即可启动全流程；包含清晰的流程启动日志，便于用户跟踪执行进度。

### 2.2.2 格式转换模块：ConvertPgmToDat.m

**目的**：将存储超声RF原始数据的.pgm格式文件（含544字节文件头）批量转换为无文件头的.int32格式二进制.dat文件，去除冗余文件头信息，统一数据格式，为后续信号处理提供纯净数据。

**核心原理**：.pgm文件是一种图像格式文件，其前544字节为文件头（包含图像尺寸、格式等信息），后续为原始RF信号数据；本模块通过跳过文件头、读取有效数据并以.int32格式写入.dat文件，实现“图像格式→二进制数据格式”的转换，保留RF信号的原始数值特征。

**实现方法**：① 配置输入输出目录、文件头大小、预期数据尺寸等参数；② 自动创建输出目录（若不存在）；③ 遍历输入目录下所有.pgm文件，逐一打开并跳过544字节文件头；④ 读取有效RF数据并验证数据长度（确保完整性）；⑤ 将数据以.int32格式写入对应的.dat文件；⑥ 输出处理进度与结果日志。

**关键参数**：header_size=544（.pgm文件头大小）、expected_size=3716×760（单文件预期数据量，对应3716个样本点/扫描线×760条扫描线）。

### 2.2.3 信号导入与预处理模块：SignalImportAndPreprocess.m

**目的**：从转换后的.dat二进制文件中导入超声RF信号，完成“二进制→十进制”转换、一维数据→二维矩阵重塑（匹配超声扫描结构）及目标扫描线归一化，为后续频谱分析与信号处理提供标准化数据。

**核心原理**：超声RF信号在.dat文件中以二进制形式存储，需通过读取函数转换为十进制数值；超声扫描数据天然具有“扫描线×样本点”的二维结构，将一维读取的数据重塑为二维矩阵，可直观对应实际超声扫描的空间分布；归一化处理（映射到[0,1]区间）可消除信号幅度差异，便于时域波形观察与对比。

**实现方法**：① 配置.dat文件路径、单条扫描线样本点数、扫描线总数、采样频率等参数；② 以二进制只读模式打开.dat文件，读取数据并转换为.int32格式十进制数值；③ 验证数据长度（与预期一致，确保无数据丢失）；④ 将一维数据重塑为[760×3716]的二维矩阵（760条扫描线，每条3716个样本点）；⑤ 提取目标扫描线（默认第1条）并进行归一化（min-max标准化）；⑥ 输出处理后的二维数据矩阵、归一化扫描线等结果。

**输出结果**：image_data（二维RF数据矩阵）、normalized_scan_line（归一化目标扫描线）、scan_line（原始目标扫描线）、params（配置参数）。

### 2.2.4 频谱分析与中心频率确定模块：SpectrumAnalysisAndCenterFreq.m

**目的**：对预处理后的RF信号进行时域-频域分析，通过快速傅里叶变换（FFT）确定信号中心频率，完成基带移频（将中心频率移至零频率附近），为后续低通滤波提供条件。

**核心原理**：超声RF信号是调制信号，其能量集中在中心频率附近；通过FFT可将时域信号转换为频域信号，获取信号的频率分布特征；找到频域中最大幅度对应的频率即为中心频率；利用复指数信号与原始信号相乘，可实现信号的频域平移（移频），将调制信号转换为基带信号（中心频率接近零频率），便于后续低通滤波去除高频噪声。

**实现方法**：① 创建时域-频域分析图形窗口，绘制归一化目标扫描线的时域波形；② 对原始目标扫描线进行FFT，提取正频率部分，绘制幅度谱并标记正频率中心频率；③ 分析全频谱（含正负频率），验证并确定最终中心频率；④ 创建信号处理过程对比窗口，绘制原始信号时域波形、原始频谱、移频后频谱；⑤ 利用复指数信号完成基带移频，输出移频后的基带信号；⑥ 预留滤波后频谱绘制区域（供后续滤波模块填充）。

**关键技术**：FFT变换、频谱移位（fftshift）、复指数移频算法。

### 2.2.5 滤波器设计与批量信号滤波模块：FilterDesignAndBatchProcess.m

**目的**：设计FIR低通滤波器，对移频后的基带信号进行滤波（去除高频噪声与杂波），并批量处理所有760条扫描线，确保全数据的信号纯净度。

**核心原理**：移频后的基带信号能量集中在零频率附近，高频部分主要为噪声；FIR低通滤波器具有线性相位特性，可在滤除高频噪声的同时，避免信号波形失真；批量处理所有扫描线，可确保后续成像数据的一致性。

**实现方法**：① 配置滤波器参数（通带截止频率、阻带截止频率、通带波纹、阻带衰减等）；② 利用Matlab的designfilt函数设计FIR低通滤波器（阻带衰减60dB，保证滤波效果；通带波纹0.5，减少信号失真）；③ 对单条基带信号进行滤波，取实部（滤除移频引入的虚部噪声），绘制滤波后频谱并填充至之前预留的图形区域；④ 预分配内存（提升处理效率），批量对760条扫描线执行“移频→滤波”操作；⑤ 输出批量滤波后的二维数据矩阵、滤波器参数等结果。

**关键参数**：f_cutoff_stop=5MHz（阻带截止频率）、f_cutoff_pass=2.275MHz（通带截止频率）、SampleRate=40MHz（采样频率）。

### 2.2.6 信号抽取与B超矩形成像模块：SignalDecimationAndBModeImaging.m

**目的**：对滤波后的信号进行下采样抽取（降低数据量，提升后续处理效率），通过图像增强算法（对数变换、动态范围压缩等）处理数据，最终生成灰度B超矩形图像。

**核心原理**：滤波后的信号仍存在大量冗余样本点，下采样抽取（抽取因子D=4）可在不丢失关键信息的前提下，将数据量压缩为原来的1/4；超声B超图像的核心是“灰度反映信号幅度”，通过对数变换可压缩信号动态范围（突出弱信号细节），动态范围压缩与百分位数截断可剔除极端值（优化对比度），gamma校正可提亮暗部区域，最终生成符合人眼观察习惯的灰度图像。

**实现方法**：① 配置抽取因子（D=4），对单条滤波后信号进行下采样抽取，绘制抽取后信号频谱（验证无混叠失真）；② 预分配B超成像矩阵，批量对760条扫描线执行“滤波→抽取”操作，统一矩阵尺寸（填充零至固定长度）；③ 执行图像增强流程：对数变换（20*log10(abs(x)+1)）→ 动态范围压缩（50dB）→ 百分位数截断（5%~95%）→ 归一化（[0,1]）→ gamma校正（gamma=0.7）；④ 创建图形窗口，绘制优化后的灰度B超矩形图像（colormap(gray)）；⑤ 输出归一化B超图像、成像参数等结果。

**关键技术**：下采样抽取（downsample函数）、对数动态范围压缩、gamma校正。

### 2.2.7 图像重排模块：ImageRearrangement.m

**目的**：对生成的B超矩形图像进行转置重排，调整图像数据的维度对应关系（样本点×扫描线），使其匹配后续凸阵探头扇环图像转换的坐标映射要求，为扇环变换做数据结构准备。

**核心原理**：矩形B超图像的原始维度为“扫描线×样本点”（行=扫描线，列=深度样本点），而扇环变换需要“深度样本点×扫描线”的维度（行=深度，列=扫描线）才能正确映射极坐标与笛卡尔坐标的对应关系；通过矩阵转置，可直接调整维度对应关系，无需改变数据本身的灰度特征。

**实现方法**：① 对输入的归一化B超矩形图像执行转置操作；② 读取重排后图像的尺寸信息（样本数×扫描线数）；③ 验证重排效果（确保扫描线与深度样本的对应关系正确）；④ 输出重排后的图像数据与尺寸信息。

**核心操作**：矩阵转置（ultrasound_image_norm = ultrasound_image_norm'）。

### 2.2.8 扇环图像转换模块：SectorImageTransformation.m

**目的**：将重排后的矩形B超图像转换为凸阵探头对应的扇环B超图像（极坐标→笛卡尔坐标映射），添加扇环边界线提升可读性，保存全流程核心结果，最终完成B超图像重建。

**核心原理**：凸阵探头的超声扫描轨迹为扇环形（极坐标分布），而之前生成的是矩形图像（笛卡尔坐标）；通过将“深度样本点”映射为极坐标的“半径”、“扫描线”映射为极坐标的“角度”，再将极坐标（R,θ）转换为笛卡尔坐标（X,Y），可实现矩形图像到扇环图像的映射；添加内弧、外弧及左右边界线，可明确扇环成像区域，符合临床观察习惯。

**实现方法**：① 配置凸阵探头参数（扫描角度65°、起始半径50像素、结束半径800像素等）；② 生成极坐标网格（角度θ：-32.5°~32.5°，半径r：50~800像素）；③ 将极坐标（θ,R）转换为笛卡尔坐标（X=R·sinθ，Y=R·cosθ）；④ 创建图形窗口，利用pcolor函数绘制扇环图像，采用插值着色提升平滑度，设置等轴比例避免图像变形；⑤ 添加红色虚线边界（内弧、外弧、左右边界）；⑥ 保存核心处理结果（重排图像、参数、坐标数据等）至.mat文件；⑦ 输出全流程完成日志。

**关键参数**：scan_angle=65°（凸阵探头扫描角度）、radius_start=50（起始半径，避开探头盲区）、radius_end=800（最大成像深度）。

# 三、B超成像全流程步骤详解

## 3.1 流程总览

原始.pgm RF数据 → 格式转换（.pgm→.dat） → 信号导入与预处理 → 频谱分析与中心频率确定 → 滤波设计与批量滤波 → 信号抽取与矩形B超成像 → 图像重排 → 扇环B超图像转换 → 结果保存与可视化

## 3.2 各步骤详细执行逻辑

### 步骤1：原始数据准备与格式转换（ConvertPgmToDat.m）

用户将采集到的超声RF原始.pgm文件放置于指定目录（./raw_data/RF/2025_12_25__14_50_56/）；模块自动遍历该目录下所有.pgm文件，跳过544字节文件头后读取有效RF数据，以.int32格式批量保存为.dat文件至wht_liver_dat/目录，完成“图像格式→二进制数据格式”的转换，为后续信号处理提供纯净数据。

### 步骤2：信号导入与预处理（SignalImportAndPreprocess.m）

从wht_liver_dat/目录读取指定.dat文件，将二进制数据转换为十进制数值；验证数据长度完整性后，将一维数据重塑为[760×3716]的二维矩阵（匹配760条扫描线、每条3716个样本点的超声扫描结构）；提取第1条扫描线作为目标分析线，通过min-max标准化将其映射到[0,1]区间，便于后续时域-频域分析。

### 步骤3：频谱分析与中心频率确定（SpectrumAnalysisAndCenterFreq.m）

先绘制目标扫描线的归一化时域波形，直观展示信号的时域变化特征；对原始目标扫描线执行FFT变换，提取正频率部分绘制幅度谱，标记正频率中心频率；通过全频谱分析验证并确定最终中心频率（本项目中为-5.05MHz）；利用复指数信号与原始信号相乘，完成基带移频（将中心频率移至零频率附近），绘制原始信号与移频信号的频谱对比图，预留滤波后频谱绘制区域。

### 步骤4：滤波设计与批量滤波（FilterDesignAndBatchProcess.m）

基于40MHz采样频率，设计FIR低通滤波器（通带2.275MHz、阻带5MHz、阻带衰减60dB）；对单条移频后的基带信号进行滤波，取实部滤除虚部噪声，绘制滤波后频谱并填充至步骤3预留的图形区域；预分配内存后，批量对760条扫描线执行“移频→滤波”操作，输出批量滤波后的二维数据矩阵，确保全数据的信号纯净度。

### 步骤5：信号抽取与矩形B超成像（SignalDecimationAndBModeImaging.m）

设置抽取因子D=4，对滤波后的信号进行下采样抽取，将数据量压缩为原来的1/4（提升后续处理效率），绘制抽取后信号频谱验证无混叠失真；批量对760条扫描线执行“滤波→抽取”操作，构建B超成像矩阵；通过“对数变换→动态范围压缩→百分位数截断→归一化→gamma校正”的图像增强流程，优化图像对比度与细节表现力，最终绘制并输出优化后的灰度B超矩形图像。

### 步骤6：图像重排（ImageRearrangement.m）

对生成的B超矩形图像执行转置操作，将维度从“扫描线×样本点”调整为“样本点×扫描线”，使数据结构匹配后续扇环变换的极坐标-笛卡尔坐标映射要求，确保扇环图像转换的准确性，无需改变图像本身的灰度特征。

### 步骤7：扇环图像转换与结果保存（SectorImageTransformation.m）

配置凸阵探头参数（65°扫描角度、50~800像素半径范围），生成极坐标网格并转换为笛卡尔坐标；利用pcolor函数绘制扇环图像，采用插值着色提升平滑度，添加红色虚线边界（内弧、外弧、左右边界）明确成像区域；将重排图像、参数、坐标数据等核心结果保存至.mat文件；输出全流程完成日志，最终生成符合临床观察习惯的凸阵探头扇环B超图像。

# 四、生成图像详细说明

本项目共生成5幅核心图像，覆盖“时域-频域分析”“信号处理对比”“抽取后频谱”“矩形B超”“扇环B超”五大关键环节，每幅图像均包含清晰的标题、坐标轴标注与网格，便于直观观察与分析。

## 4.1 图像1：超声扫描线时域+频域分析结果
